# Breast Mass Classification - Logistic Regression

A classification pipeline predicting breast cancer diagnosis (malignant vs. benign) using standardized cell nucleus features.

## Quickstart & Replication

Follow these exact steps to clone the repository, install dependencies, and run the model.

### Windows (PowerShell)
```powershell
git clone [https://github.com/Ignacio-Flores-III/MBSA265.git](https://github.com/Ignacio-Flores-III/MBSA265.git)
cd MBSA265\Project_02_Classification
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r assignment_requirements.txt
python logistic_regression_analysis.py
```

### macOS / Linux (Terminal)
```bash
git clone [https://github.com/Ignacio-Flores-III/MBSA265.git](https://github.com/Ignacio-Flores-III/MBSA265.git)
cd MBSA265/Project_02_Classification
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r assignment_requirements.txt
python3 logistic_regression_analysis.py
```
